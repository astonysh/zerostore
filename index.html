How it works

The same three steps the agents are running in public. The free kit covers step 3; Pro adds the agent skills for steps 1–2 and the launch playbook.

1

Find a niche with proof

Look for buyers who already pay: marketplace review counts, competitor prices, real threads. Skip anything that needs an audience you don't have.

2

Build the product in days

Templates, spreadsheets, starter kits, guides — things an AI coding agent can produce and a human can check in an afternoon.

3

Ship a storefront on GitHub Pages

Edit one config.json, push, and a GitHub Action publishes a fast landing page with checkout, sitemap and robots.txt. Free hosting, forever.

What's in the free kit

MIT licensed. No build tools to install — Node is only used inside the GitHub Action.

npx degit astonysh/zerostore/kit my-store
cd my-store
# edit config.json: name, price, CHECKOUT_URL, copy, FAQ
node scripts/build.mjs        # optional local preview → dist/index.html
git init && git add -A && git commit -m "my store"
# push to GitHub → Settings → Pages → Source: GitHub Actions

One-file landing page

Hero, features, pricing, FAQ, footer. Dark and light themes. Loads in well under a second.

Checkout that just works

Gumroad overlay, Lemon Squeezy overlay, or Payhip — switch with one config field. They handle cards, PayPal and sales tax.

SEO basics done

Open Graph tags, JSON-LD product data, canonical URL, auto-generated sitemap.xml and robots.txt.

FAQ

Straight answers.

Will this make me money?

No promise. Most digital products earn little or nothing in their first month, and we may miss $500 too. What you get is working tooling and an honest record of what did and didn't work. Pro is for people who want the full playbook and agent skills.

Do I need a domain or a server?

No. The storefront runs on GitHub Pages at yourname.github.io/your-store. You can add a custom domain later if you want.

How do I get paid?

Through Gumroad, Lemon Squeezy or Payhip. They act as the checkout and take care of cards, PayPal and sales tax. Setup takes about 10 minutes and the free kit includes a step-by-step guide. Payout methods differ by country — check your platform's payout settings before you launch.

Which AI agents do the Pro skills work with?

They use the open SKILL.md format, so they work with Claude Code and with other agents that read it (Codex CLI, Cursor, Gemini CLI). They're plain Markdown, so you can also read and follow them by hand.

Who is behind this?

One human who owns the GitHub account, plus two AI agents that did the research, wrote the code and drafted the copy. The human approves anything that gets published or posted.

Can I get a refund?

Yes — 14 days, no questions asked. Email via the Gumroad receipt.

Are the numbers real?

Yes. Revenue, orders and spend are copied from the payment dashboard into log/data.json in the public repo, so every change is in the git history. No fake testimonials, no screenshots we can't back up.
